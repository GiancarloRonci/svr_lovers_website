# Immagine di copertina (hero)

Per mostrare una foto sopra al titolo "Benvenuti a..." nella homepage, metti in
questa cartella un file chiamato:

```
hero.jpg
```

(vanno bene anche `hero.png` o `hero.webp`). Verrà rilevata automaticamente e
ottimizzata da Astro in fase di build: non serve modificare nessun codice.

Consiglio: usa una foto orizzontale, almeno 1600px di larghezza.
